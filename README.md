# ComfyUI Ultimate Colab

A Google Colab launcher for ComfyUI with Google Drive integration, cloudflared access, and a clean setup flow.

## Status

Initial scaffold.

## Planned features

- Google Drive mount and symlink setup
- ComfyUI install/update helper
- Cloudflared tunnel launcher
- Model folder linking from Drive
- Custom node bootstrap
- Starter notebook for one-click launch
